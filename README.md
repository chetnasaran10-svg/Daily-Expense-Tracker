# 💰 SpendWise – Personal Expense Tracker

**SpendWise** is a modern and user-friendly Personal Expense Tracker website designed to help users organize, monitor, and understand their daily spending.

The project features a clean dashboard, expense entry form, transaction history, and category-wise spending breakdown.

## 🌟 Features

- Modern and attractive dashboard UI
- Total Balance, Income, and Expenses cards
- Add Expense form
- Expense categories
- Recent Transactions table
- Category-wise spending breakdown
- Responsive design for mobile and desktop
- Simple and beginner-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate `index.html`.
4. Open it in your web browser.
5. Explore the SpendWise dashboard.
